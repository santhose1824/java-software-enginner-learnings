## Why this repo

I'm working through [Striver's A2Z sheet](https://takeuforward.org/strivers-a2z-dsa-course/strivers-a2z-dsa-course-sheet-2) to build interview-ready problem solving in **Java** — the language I want to work in.

The goal isn't a high solve count. It's owning a set of patterns well enough to recognise them cold.

**My method:** attempt the brute force first → if stuck 25 minutes, read the editorial and understand it → **re-solve from a blank file two days later.** The re-solve is where it actually sticks.
