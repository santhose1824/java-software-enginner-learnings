# Order Notification System

## Problem Statement

Imagine you've placed an order, and the next steps involve sending three notifications:

| # | Notification | Time Taken |
|---|--------------|-----------|
| 1 | Send an **SMS** | 2 seconds |
| 2 | Send an **Email** | 3 seconds |
| 3 | Send **ETA** (Estimated Time of Arrival) | 5 seconds |
